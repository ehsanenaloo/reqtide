Install with Composer#

composer require enaxon/reqtide

Add the optional packages when you need them. Each one requires exactly the same version of enaxon/reqtide:

composer require enaxon/reqtide-redis    # state shared by several PHP processes
composer require enaxon/reqtide-guzzle   # protections around Guzzle requests

The vendor name is enaxon. A different Packagist vendor, naxon, is one letter apart: copy the package name exactly.

Requirements#

  • PHP 8.3 or newer on a 64-bit build (php-64bit).
  • Composer 2.
  • No other runtime dependencies. composer.json requires only php and php-64bit.

Install from a clone (for contributors)#

Step 1: Clone the repository

Clone it next to your project:

git clone https://github.com/ehsanenaloo/reqtide.git

Step 2: Register the clone as a path repository

In your project's composer.json, add the repository. symlink: false makes Composer copy the package into vendor/ instead of linking it:

{
    "repositories": [
        { "type": "path", "url": "../reqtide", "options": { "symlink": false } }
    ]
}

Step 3: Require the package

composer require "enaxon/reqtide:@dev"

The vendor name is enaxon. A different Packagist vendor, naxon, is one letter apart: copy the package name exactly and check the vendor before you run composer require.

One package, enaxon/reqtide, contains the library (Enaxon\Reqtide) and the test helpers (Enaxon\Reqtide\Testing). The helpers are installed with it and are meant for tests only. The archive you install holds src/, docs/, composer.json, README.md, LICENSE and CHANGELOG.md. Tests, tools and examples stay in the repository.

Try it without installing PHP#

If you have Docker, run the examples inside the clone. No PHP or Composer is needed on your machine:

cd reqtide
docker compose -f tools/docker/compose.yaml run --rm php83 composer install
docker compose -f tools/docker/compose.yaml run --rm php83 php examples/06-getting-started.php

The output is:

ok on attempt 3
invocations: 3

Use php84 or php85 in place of php83 to try the other versions.

Check that it works#

Create demo.php in your project with the script from Getting started and run:

php demo.php

You should see the two lines above. If PHP reports Class "Enaxon\Reqtide\Pipeline\PipelineBuilder" not found, the autoloader line is missing or points to the wrong vendor/ folder. If Composer reports that it cannot find enaxon/reqtide, check the url of the path repository.

Read these docs offline#

The docs/ folder is a static site with no build step. Open docs/index.html in a browser, or serve it:

php -S 127.0.0.1:8766 -t docs
