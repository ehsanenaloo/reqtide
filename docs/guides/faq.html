Install and status#

Is it on Packagist?

No. The package enaxon/reqtide is not published, and there is no tagged release. Install it from a clone as described in Install.

Is it ready for production?

No claim is made. It is alpha: names and behavior may change, and the core package keeps its state in one process. It was run on the command line in Docker, not under PHP-FPM. See Limits.

Which PHP versions work?

PHP 8.3 or newer on a 64-bit build. The tests and examples were run in Docker on 8.3, 8.4 and 8.5.

Does it need any other packages?

No. composer.json requires only php and php-64bit. The test helpers are in the same package.

Does it work with Guzzle, PSR-18 or Symfony HTTP Client?

A Guzzle integration, enaxon/reqtide-guzzle, exists as a separate package in the development repository. It is not released, not on Packagist, and was run only in local Docker with Guzzle 7.15.5 and PHP 8.3 to 8.5 on the command line. PSR-18 and Symfony HTTP Client have no integration: you wrap a call made with one of those clients in a pipeline yourself. See Guzzle requests with Reqtide and Limits.

Is there Redis support?

Not in the core package, whose state lives in the memory of one PHP process. A separate package, enaxon/reqtide-redis, shares state between processes. It exists in the development repository, is not released and not on Packagist, and was run only in local Docker with Redis 7.4.11 and 8.2.10 and PHP 8.3 to 8.5 on the command line. Sentinel, Cluster, Valkey and PHP-FPM are not supported. See Shared state with Redis and Limits.

Behavior#

Does it retry a POST?

Only if you tell it that repeating the call is safe. A retry needs three things: your replay-safety assertion for the call, a retry budget, and a retryable exception class. Reqtide never infers safety and has no HTTP knowledge. See Getting started.

Are limits shared across PHP-FPM workers or servers?

No. State is per process. A pipeline built inside a request starts every request with a full quota and a closed circuit. See Limits.

Does it stop a callback that runs too long?

No. The deadline is checked between steps. A result that arrives after the deadline is reported as DeadlineExceeded, but your code has already run to the end. Declare the attempt timeout as Cooperative and make your code stop itself.

Does it guarantee exactly-once execution?

No. Design the operation to be safe to repeat, or do not retry it.

Why are there no default timeouts or limits?

A default would be a guess about your dependency. You pick every number, and the builder tells you which required decision is missing.

Why was my rate limit charged for a call that never ran?

A rate charge is never refunded. If a call is cancelled after admission and before dispatch, its unit stays used. See Limits.

Errors#

How do I tell my own exceptions from Reqtide's decisions?

Your exceptions come out unwrapped. A refusal by Reqtide is a ReqtideException, and the ones that describe a policy decision also implement ProblemCarrier, with a stable ReasonCode and a redacted Problem. Branch on those, not on message text. See Error handling.

What does rate.exhausted or circuit_open mean?

The rate limit or the circuit breaker refused the call before your code ran. The Problem says whether to wait, retry or fix the setup. See Error handling.

Testing#

How do I test retries without sleeping?

Use the virtual clock and the scripted runtime from Enaxon\Reqtide\Testing. Time moves only when you move it, and each attempt returns what you script. See Testing.

Can I use the test helpers in production code?

They are for tests. They ship in the same package, so they are also in production installs, but production code should not call them.

Using these docs#

Do the code examples really run?

Yes. Every PHP code block and every output block comes from a script in examples/ that the project runs and compares with recorded output. A check fails when a block on a page is not an excerpt of an executed script. The check is not a support claim: it ran in Docker on the command line.

Where is the full list of classes and methods?

The API reference. Its signature listings are generated from the real classes in src/ and checked against them.

Can I read the docs offline?

Yes. The docs/ folder is plain HTML, CSS and JavaScript with no build step and no external requests. Open docs/index.html in a browser.

Contributing#

How do I report a bug or ask for a feature?

Open an issue. Do not include secrets or production data. Report security problems privately, as described in the security policy.
