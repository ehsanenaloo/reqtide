# Upgrade guide

Nothing has been released yet, so there is nothing to upgrade from.

Before 1.0.0, a minor release may contain breaking changes. Each one will be listed here with the steps to migrate. The three packages (`enaxon/reqtide`, `enaxon/reqtide-redis` and `enaxon/reqtide-guzzle`) share one version number. Upgrade them together.

Changes that do not break existing code are listed only in [CHANGELOG.md](CHANGELOG.md).
